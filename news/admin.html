깃허브 토큰

"게시하기"로 바로 올리려면 seumarena 저장소에 쓸 수 있는 토큰이 필요해요. 토큰은 이 기기의 브라우저에만 저장돼요.

  1. 새 fine-grained 토큰 만들기
  2. Repository access: Only select repositories → seumarena
  3. Permissions → Repository → Contents: Read and write
  4. 만든 토큰(github_pat_…)을 아래에 붙여 넣기

news.json

토큰 없이 올릴 때는 이 내용을 복사해서 Claude에게 주거나, 저장소의 news/news.json에 붙여 넣으면 돼요.
